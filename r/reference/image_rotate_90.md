# Rotate an image by 90 degrees

Rotate an image by 90 degrees

## Usage

``` r
image_rotate_90(image, clockwise = TRUE)
```

## Arguments

- image:

  An image list.

- clockwise:

  Logical, if `TRUE` (default) rotates clockwise, otherwise
  counter-clockwise.

## Value

A new image list with width and height swapped.
