Detailed Description

Size of a (possibly multi-line) piece of text.

The text box used by the renderer: width is the width of the widest line, height the height of the whole block, and the anchor is placed on this box with TextLayer::adj. Use it for layout decisions such as "which corner is still free for a caption", or to centre a title.
