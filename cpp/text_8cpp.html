Detailed Description

Implementation of the text layer (see text.h).

Rendering works in "screen" coordinates with the origin at the top left and y growing downwards, which is both what ndc_to_screen() returns and the row order of Image (row 0 is the top row of the written file). Glyph bitmaps from stb_truetype are top-down as well, so no flipping is involved anywhere.
